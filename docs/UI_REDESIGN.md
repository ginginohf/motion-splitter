# Обновление интерфейса — 0.17.4

- Собственная иконка: редактируемый SVG, PNG, ICO для Windows и ICNS для macOS.
  Linux-пакет устанавливает значок в hicolor; модель в установщик не включается.
- Две вкладки с последовательностью «видео → параметры → результат».
- Светлая и тёмная палитры, заголовок приложения, визуальные группы без плотной сетки.
- Выпадающие списки для экспорта, автоматического/ручного режима, размера анализа,
  типа модели и масштаба. Подписи отделены от сохраняемых значений настроек.
- Числовые поля со стрелками; колесо меняет только поле с фокусом. В остальных
  случаях прокручивается форма. Ручной ввод и прежняя валидация сохранены.
- Дополнительные параметры движения, пресеты, пути моделей и ресурсы скрыты
  в раскрывающихся разделах. Все прежние настройки доступны.
- Одна постоянная панель запуска/отмены/сохранения; действие запуска зависит
  от выбранной вкладки. Настройки и пресеты используют прежнюю схему хранения.

## Проверено на macOS arm64

148 unit/media integration тестов, четыре проверки настоящего Tk-окна.
Проверки расширены: выбор модели и разрешённого масштаба, синхронизация значений,
колесо с фокусом/без фокуса, раскрытие секций и навигация при 900×640.
Светлая и тёмная темы просмотрены на локальных скриншотах.

PKG 0.17.4 прошёл проверку подписи, 126 Mach-O без внешних несистемных зависимостей,
обработки тестового видео и полного App с пустым PATH. Иконка включена в bundle.
Приложение в /Applications обновлено; предыдущая копия сохранена отдельно.
Windows/Linux значки подключены к упаковке, но нативно здесь не проверялись.
Пакет остаётся development-сборкой, не публичным релизом.

Локальные артефакты: tests/ci-artifacts/redesign-*.png, core-summary.json,
gui-summary.json, package-0174.json; dist/macos-arm64-development.
