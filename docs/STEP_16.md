# Этап 16 — автоматические проверки и GitHub Actions

Добавлены .github/workflows/ci.yml и единая команда tools/check_ci.py.
Workflow подготовлен и проверен локально; фактического запуска GitHub Actions
ещё нет: remote у локального репозитория не настроен. Windows/Linux пока не
считаются проверенными ОС. Это не сборка установщиков и не публикация релиза.

## Состав CI

События: push, pull_request, ручной workflow_dispatch. Матрица:

| Runner | Python | Проверки |
|---|---|---|
| ubuntu-24.04 | 3.10 | Синтаксис, зависимости, unit/media tests |
| ubuntu-24.04 | 3.12 | То же + четыре Tk-проверки под Xvfb |
| windows-2022 | 3.12 | То же + четыре Tk-проверки |
| macos-15 (arm64) | 3.12 | То же + четыре Tk-проверки и actionlint |

Требуемые внешние инструменты устанавливаются пакетным менеджером ОС.
Для генерации и большинства media-тестов используется FFmpeg из фиксированного
imageio-ffmpeg; FFprobe берётся из установленного комплекта ОС. Версии записываются
в журналы. Системные пакеты могут обновляться; CI не является бит-в-бит
воспроизводимой сборкой установщиков. Их версии закрепляются в этапе 17.

Workflow использует contents: read, отключённое сохранение checkout credentials,
SHA-привязки официальных actions, pip cache, timeout 20 минут и отмену устаревших
прогонов одной ветки/PR. Ошибка одного элемента матрицы не отменяет остальные.
Dependabot ежемесячно предлагает обновления GitHub Actions. Публикации, secrets
и загрузки моделей в этом workflow нет.

Артефакт checks-<OS>-py<version> сохраняет tests/ci-artifacts/ даже при ошибке,
если каталог успел появиться. Хранение — 14 дней. Он содержит вывод проверок,
версии зависимостей/инструментов и core-summary.json/gui-summary.json со статусами
и временем стадий. Временные видео и личные настройки не загружаются. Частные
временные журналы отдельных unittest могут удаляться самими тестами; в артефакте
остаётся общий stdout/stderr набора с traceback.

## Локальный запуск

```sh
python tools/check_ci.py
python tools/check_ci.py --gui-only
```

Первая команда проверяет синтаксис без записи pyc, pip check, версии инструментов,
создаёт отсутствующие синтетические видео и запускает unittest discover -v.
Если набор fixtures неполон, команда завершается ошибкой без перезаписи
оставшихся файлов. Удалять/переносить тестовый набор пользователь решает отдельно.
Вторая требует готовые fixtures и графическую сессию (или Xvfb на Linux).

В тестах Windows POSIX-проверка killpg пропускается явно. POSIX-скрипт-имитатор
нейросети на Windows запускается адаптером через тот же Python; настоящий
ProcessRunner, Python-процессы и FFmpeg продолжают работать. Это не подтверждение
запуска нейросети на GPU. Остальные POSIX-only skips уже существовали в наборе.

## Фактически выполнено

На локальной macOS arm64 / Python 3.9.6:

- Единый core-сценарий: 142 теста, без ошибок; pip check пройден.
- Все четыре GUI-проверки через --gui-only: настройки, задачи/отчёты,
  закрытие с остановкой FFmpeg, обе темы/компоновка 900×640 — пройдены.
- Чистая временная копия дерева без .venv, fixtures и прошлых артефактов:
  fixtures созданы заново, 142 теста прошли. Использован существующий интерпретатор
  с зависимостями; это не проверка установки зависимостей в новом окружении.
- actionlint 1.7.12: workflow прошёл проверку; YAML также разобран Ruby/Psych.
- Новые тесты: неполный набор fixtures не перезаписывается, GUI без fixtures
  завершается с ошибкой и JSON-итогом, синтаксическая ошибка выявляется до тестов.

До релиза нужен реальный зелёный прогон всех элементов матрицы и тестирование
готовых установщиков на чистых ОС. Неудача job не должна обходиться добавлением
continue-on-error или фиктивным пропуском платформы.

## Уточнение релиза пользователя

Установщики теперь обязательны: Windows .exe через Inno Setup, macOS .pkg,
Linux .deb (Debian/Ubuntu). Внутри — FFmpeg и FFprobe, модели скачиваются отдельно
из официального репозитория. Требования: [INSTALLERS.md](INSTALLERS.md).
Этап 17 разбит на отдельные сессии до пяти часов; прежнее исключение «сборки
для всех ОС» удалено из границ релиза.

Источники: [GitHub-hosted runners](https://docs.github.com/en/actions/reference/runners/github-hosted-runners),
[setup-python](https://github.com/actions/setup-python),
[upload-artifact](https://github.com/actions/upload-artifact).
