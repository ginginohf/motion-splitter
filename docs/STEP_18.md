## Скриншоты и приватность

Сняты отдельные реальные окна App с копией стандартных настроек, без изменения
пользовательского файла настроек. Снимки захватывают только окно, без наложений
других приложений. Обе картинки просмотрены: личных видео, путей и логов нет.
[Описание снимков](screenshots/README.md).

Для светлой темы использован отдельный запуск. При переключении темы в одном
сеансе на раннем снимке рисунок внутри иконки отображался неполностью; в свежем
светлом окне он отображается. Это наблюдение нужно повторно проверить на этапе 19,
включая перерисовку иконки при смене темы; документация не означает закрытие этой проверки.
