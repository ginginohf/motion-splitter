# Этап 17 — упаковка: выполненная часть и приёмка

Статус: **частично выполнен**, весь этап пока не закрыт. Подготовлены сценарии
трёх форматов, локально собран тестовый PKG macOS arm64 версии 0.17.0.
Это не первый публичный релиз. Windows/Linux здесь не собирались.

## Изменения

- PyInstaller spec и единая команда `tools/build_installer.py`; версии упаковщика
  и hooks закреплены в `requirements-build.txt`.
- Windows: Inno Setup, стабильный AppId, установка для текущего пользователя,
  ярлык и деинсталляция. macOS: `.app` → `.pkg`. Linux: `.deb`, desktop entry и
  заявленные системные зависимости для начальной базы Ubuntu 24.04 amd64.
- FFmpeg/FFprobe входят в пакет; frozen-приложение ищет только свои бинарники,
  без скрытого перехода к PATH. Отсутствующий бинарник выдаёт ошибку.
- Входной vendor-манифест проверяет SHA-256, целевую платформу и наличие сведений
  об источнике/лицензиях. Итоговый установщик получает SHA256SUMS и build-info.
  Проверка наличия документов не заменяет проверки их содержания.
- Найден и устранён конфликт библиотек FFmpeg с одноимёнными библиотеками OpenCV:
  в macOS комплект внешних инструментов изолирован; install names меняются только
  в копиях сборки. Зависимости фиксируются отдельными SHA-256.
- Подпись/упаковка macOS выполняются во временном каталоге: Finder в Documents
  добавлял атрибуты к `.app`/`.framework` во время подписи. Применяется техническая
  ad-hoc подпись; Developer ID и нотариальное заверение отсутствуют.
- В интерфейсе обеих вкладок есть отдельная папка моделей, ссылка на официальный
  репозиторий и проверка файлов. Настройка общая и сохраняется в пресетах,
  схема настроек повышена с 5 до 6. Старые настройки дополняются новым полем.
- Веса не входят в установщик. Движок устанавливается отдельно по
  [инструкции](MODELS.md); GPU проверяется пробным запуском перед обработкой.

## Проверки

- 148 unit/integration-тестов прошли, включая новые проверки путей frozen-сборки,
  моделей в отдельной папке, старого размещения, XDG и повреждённого vendor-комплекта.
- Четыре проверки исходного Tk GUI прошли: настройки, потоки, закрытие, компоновка.
- Локальная сборка macOS: Python 3.9.6, PyInstaller 6.22.0,
  hooks 2026.10, FFmpeg/FFprobe Homebrew 9.0.2. Это development-комплект,
  его полные уведомления/исходники зависимостей ещё не подготовлены для распространения.
- Frozen self-test с пустым PATH из другого каталога: генерация H.264/AAC,
  concat/setts, поиск движения, точный экспорт с проверкой результата.
- PKG распаковывается без установки в `/Applications`; проверка Mach-O итогового
  пакета нашла 120 файлов без абсолютных ссылок на внешние несистемные библиотеки.
  После распаковки прошли self-test с пустым PATH и создание/закрытие окна Tk.
  Результат итоговой проверки хранится в `tests/ci-artifacts/package-final.json`.
  Это не заменяет установку на чистой машине и не доказывает поддержку старых macOS.

Артефакт: `dist/macos-arm64-development/MotionSplitter-0.17.0-macos-arm64-development.pkg`.
Логи/сборки не включаются в Git. [Команды сборки](../packaging/README.md).
