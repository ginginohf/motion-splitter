# Этап 11 — экспорт и проверка результатов

Реализованы fast (копирование потоков, исходный контейнер) и accurate
(MP4/H.264/AAC). Выбор доступен в GUI, сохраняется в настройках и пресетах.
Схема 3 автоматически дополняет старые настройки значением fast.

В обоих режимах выбраны первый обычный видеопоток и первая аудиодорожка;
субтитры, вложения и главы не копируются. Точный режим использует входной
seek с декодированием до выбранного начала, длительность задаётся через -t.
CRF 18, preset medium, yuv420p, AAC 192k; нечётные размеры дополняются до чётных.

FFprobe ищется рядом с FFmpeg, в каталоге проекта, ffmpeg/bin, tools/bin и PATH.
Его доступность проверяется до анализа. До атомарной публикации результата:
проверка потоков, длительности, кодеков точного режима и полное декодирование
FFmpeg с -xerror. JSON и журналы остаются в logs. Отмена работает через общий
ProcessRunner. Ошибка не публикует текущий файл и не удаляет предыдущие.
Числа сохранённых, ошибочных и незавершённых сегментов пишутся в журнал.

## Проверки

macOS arm64, Python 3.9.6, FFmpeg 7.1 из imageio-ffmpeg, FFprobe 9.0.2
(установлен вместе с FFmpeg через Homebrew).

- 103 unittest: пройдены.
- Дробный интервал 1.23–3.34 с: длительность в пределах одного кадра.
- Редкие ключевые кадры: первый кадр точного результата соответствует кадру 31
  источника при 25 FPS и начале 1.23 с.
- WebM VP9/Opus: fast сохраняет кодеки, accurate даёт MP4 H.264/AAC.
- Видео без звука и с двумя аудиодорожками: ожидаемый состав потоков.
- Ошибка проверки второго сегмента: первый сохранён, второй не опубликован,
  третий не запускался; корректные счётчики и очистка временных файлов.
- Настоящий Tkinter: автонастройка + точная нарезка + имитация улучшения;
  сохранение/загрузка нового поля и его восстановление из пресета — пройдены.

## Ограничения

Fast не обеспечивает точных границ. Проверка декодированием добавляет время.
Точный режим меняет качество/цветовой формат, не сохраняет HDR/10-bit.
Допуск длительности: max(0.1 с, два кадра по средней частоте); сложные VFR и
смещённые потоки отдельно не подтверждены. Интервал без аудиопакетов при
наличии аудиопотока источника может быть отклонён строгой проверкой.
Windows/Linux не проверены. Проверки этого этапа относятся к нарезке;
Real-ESRGAN и его сборка видео остаются этапами 12–13. Пакетный отчёт — этап 14.

Основания для параметров: [FFmpeg — seek, map и кодирование](https://ffmpeg.org/ffmpeg.html),
[FFprobe — JSON и сведения о потоках](https://ffmpeg.org/ffprobe.html).
