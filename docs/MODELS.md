# Движок и модели Real-ESRGAN

Нарезка работает без Real-ESRGAN. Веса не включаются в установщик.

1. Откройте [официальный комплект с моделями](https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.5.0).
   Выберите `realesrgan-ncnn-vulkan-20220424-<ОС>.zip`. В этих архивах есть
   папка `models`; архивы v0.2.0 из отдельного репозитория ncnn-vulkan
   содержат только движок, без весов. Базовый контракт движка соответствует v0.2.0;
   проверяйте архитектуру исполняемого файла. Наличие macOS-архива само по себе
   не подтверждает нативную поддержку Apple Silicon.
2. Распакуйте архив в пользовательскую папку. Укажите путь к
   `realesrgan-ncnn-vulkan.exe` (Windows) или `realesrgan-ncnn-vulkan` (macOS/Linux)
   в приложении. Сохраняйте сопутствующие файлы/библиотеки архива. На Unix файл
   должен быть исполняемым; Vulkan и GPU-драйвер должны поддерживаться сборкой.
3. В поле «Папка моделей» выберите распакованную `models`, содержащую `.param`
   и `.bin`. Файлы `.pth` от Python-версии не подходят. Если веса находятся
   внутри общего архива релиза, отдельная загрузка означает загрузку этого архива,
   а не несуществующей ссылки на одиночный файл модели.
4. Выберите модель и масштаб: x4plus/x4plus-anime/realesrnet-x4plus — 4;
   realesr-animevideov3 — 2, 3 или 4. Для последней имена файлов включают `-x2`,
   `-x3` или `-x4`.
5. Нажмите «Проверить файлы модели». Это проверка наличия и читаемости файлов.
   Реальный пробный запуск модели/GPU выполняется перед апскейлом; его ошибка
   попадёт в журнал. На Apple M5 проверены x4plus, x4plus-anime и animevideov3;
   realesrnet-x4plus в выбранном архиве отсутствует и аппаратно не проверена.
   Другие GPU требуют отдельной проверки.

Оба раздела интерфейса используют общую настройку папки, сохраняемую в пресетах.
Если поле пустое, сначала используется существующий пользовательский каталог:

- Windows: `%LOCALAPPDATA%\MotionSplitter\models`;
- macOS: `~/Library/Application Support/MotionSplitter/models`;
- Linux: `$XDG_DATA_HOME/MotionSplitter/models` либо `~/.local/share/MotionSplitter/models`.

Если такого каталога ещё нет, поддерживается старый `models` рядом с указанным
движком. Явно выбранная папка имеет приоритет; при ошибке в ней нет скрытого
перехода к другой модели. Каталоги не создаются и ничего не скачивается автоматически.
Обновление приложения не должно трогать модели и пользовательские настройки.
