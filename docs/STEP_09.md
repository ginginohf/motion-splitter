# Пункт 9 — предсказуемость детектора

## Изменения

- Разрешение анализа трактуется как ограничивающая рамка. `parse_resolution`
  сохраняет пропорции, не увеличивает исходник и округляет размеры до целых
  пикселей. Та же функция используется основной детекцией и автонастройкой.
- Фиксированные пять измерений заменены `TimeSmoother`: скользящее окно
  в секундах с весами по длительности интервалов между анализируемыми кадрами.
  Частично пересекающий границу окна интервал учитывается только пересечением.
  Устаревшие измерения удаляются; окно 0 возвращает исходный показатель.
- Настройка `smoothing_sec`: 0–10 с, по умолчанию 0.2 с. При 25 FPS без пропуска
  это примерно прежние пять измерений, но при другом FPS окно сохраняет
  длительность вместо количества кадров.
- Настройки `pre_motion_sec` / `post_motion_sec`: 0–3600 с, по умолчанию 0.
  Запас добавляется после фильтра минимальной длительности, обрезается по
  границам декодированного видео и затем участвует в объединении интервалов.
  Отброшенные короткие события не восстанавливаются большим запасом.
- Значения передаются через GUI → processing → analyze_video обычными числами.
  Новые аргументы необязательны, существующие вызовы ядра продолжают работать.
- В интерфейсе появились три поля. Порог подписан как порог изменения яркости,
  рядом указано направление чувствительности. Исправлена подсказка коэффициента
  автонастройки. Добавлено объяснение пропуска кадров и необходимости настройки
  порога после его изменения.
- Схема настроек повышена до версии 2. Версии 0/1 и старые пресеты получают
  новые значения по умолчанию. Все три поля сохраняются и входят в пресеты.

## Ограничения

Окно определено во времени, но показатель разницы кадров не нормализуется по
скорости объекта или времени между кадрами. Пропуск и FPS по-прежнему влияют
на величину разницы и точность границ. Если интервал между измерениями длиннее
окна, последнее измерение занимает всё окно; восстановить пропущенную активность
невозможно. Сглаживание может скрывать короткое движение, запас лишь расширяет
найденные события. Пропорции сохраняются с погрешностью округления до пикселя.

Автонастройка пока использует прежний способ оценки порога, хотя её кадры теперь
тоже уменьшаются пропорционально. Согласование автонастройки с новым сглаживанием
и выборка по всему ролику — следующий пункт 10. Проверено на macOS; GPU,
Windows/Linux на этом этапе не проверены.
