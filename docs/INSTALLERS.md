# Требования к установщикам первого GitHub-релиза

Зафиксировано по запросу пользователя на этапе 16. Установщики обязательны для
релиза; сейчас это план этапа 17, а не готовые артефакты.

| ОС | Формат | Целевая архитектура первого набора | Способ установки |
|---|---|---|---|
| Windows | .exe | x64 | Inno Setup, установка и деинсталляция |
| macOS | .pkg | arm64 | Нативный пакет с приложением .app |
| Linux | .deb | amd64 | Пакет Debian/Ubuntu |

Форматы macOS/Linux выбраны как рабочее решение. .deb не означает поддержку
всех дистрибутивов Linux. macOS Intel, Windows ARM и Linux ARM — отдельные сборки
после проверки; универсальная поддержка архитектур пока не заявляется.

## Комплект поставки

- Приложение с Python runtime, Tcl/Tk и необходимыми Python-зависимостями:
  пользователю не нужно устанавливать Python/pip.
- **FFmpeg и FFprobe включены в каждый установщик**. На чистой системе нарезка,
  экспорт и проверка результатов работают без отдельной установки инструментов.
- Пути к комплектным бинарникам вычисляются внутри установленного приложения;
  нельзя полагаться на текущую папку или случайную копию из PATH.
- Версии/источники сборок FFmpeg фиксируются; проверяются SHA-256, кодеки libx264,
  AAC, concat/setts и нужные декодеры. Для каждого комплекта сохраняются сведения
  о конфигурации, лицензиях и соответствующих исходниках/уведомлениях.
  Требования распространения проверяются для выбранной конкретной сборки:
  [официальная информация FFmpeg](https://ffmpeg.org/legal.html).
- Веса моделей **не включаются** в установщики. Обычная нарезка работает без них.

## Отдельная установка моделей

Источник: [официальный репозиторий Real-ESRGAN ncnn-vulkan](https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan),
[его Releases](https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan/releases).
Нужны совместимые пары .param/.bin, а не .pth из Python-версии.
Если модели предоставлены внутри архива релиза, инструкция должна объяснять,
какую папку из архива выбрать. Нельзя обещать отдельный файл загрузки, которого
нет в выбранном релизе.

В этапе 17 требуется:

1. Показать в интерфейсе ссылку на официальный источник, статус наличия модели
   и выбор локальной папки моделей. Автоматическая загрузка без запроса не нужна.
2. Хранить скачанные модели вне защищённой папки приложения: например,
   LocalAppData/MotionSplitter/models на Windows, Application Support/MotionSplitter/models
   на macOS, пользовательский каталог данных на Linux. Это изменение текущего
   правила «models рядом с realesrgan-ncnn-vulkan»; оно ещё не реализовано.
3. Закрепить совместимый движок realesrgan-ncnn-vulkan для каждой ОС: либо
   поставлять проверенный бинарник, либо дать точную отдельную инструкцию его
   установки. Скачивание весов само по себе не устанавливает движок или GPU-драйвер.
4. Проверять наличие файлов и пробный запуск, сохранять подробную диагностику.
   Ошибка необязательного улучшения не должна мешать запуску приложения/нарезке.

## Приёмка пакетов

- Установить на чистой поддерживаемой ОС без Python и системного FFmpeg.
- Открыть GUI, нарезать тестовое видео, проверить звук и точный экспорт.
- Проверить запуск при отсутствии модели, затем её отдельную установку.
- Проверить отмену, отчёт, пути с пробелами/кириллицей, запуск обычным пользователем.
- Проверить обновление и удаление приложения; не удалять личные видео, настройки
  и скачанные модели без явного выбора пользователя.
- Подписи Windows, подпись/нотаризация macOS и доверие пакету Linux фиксируются
  отдельно: наличие аккаунтов/сертификатов нельзя предполагать. Не выпускать
  неподписанные файлы под видом подписанных.
- GitHub Release содержит три типа установщиков, SHA256SUMS, версию, архитектуру,
  требования ОС, лицензии и ссылки на модели. Публикация остаётся этапом 20.
