# Motion Splitter icon

Original geometric mark created for this project: a split play symbol with a
motion/timeline accent. No external images or fonts are embedded.

`icon.svg` is the editable vector source. `tools/build_icons.py` reproduces PNG,
Windows ICO and macOS ICNS assets from the same geometry using Pillow.
The PNG is used in the window header; the native formats are used in packaged apps.
Linux installs the 512 px PNG into the hicolor application icon directory.
