# Скриншоты

Сняты 19 ноября 2026 с настоящего окна Tk на macOS arm64, интерфейс 0.17.4.

- `split-dark.png` — вкладка нарезки, тёмная тема, автоматическая настройка.
- `enhance-light.png` — вкладка улучшения, светлая тема.

Использовано отдельное окно с копией стандартных настроек. Настройки владельца
не менялись; видео, локальные пути, журналы и чужие окна в снимки не включены.
Захвачено именно окно приложения, без теней и наложений других приложений.
Это снимки интерфейса в ожидании, не свидетельство выполненной обработки.

При обновлении: запустите текущий App с временным файлом настроек, выберите
нужную тему и вкладку, снимите только окно, проверьте изображение и отсутствие
личных данных. Не подменяйте настоящий интерфейс нарисованным макетом.
