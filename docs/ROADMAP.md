# План первого релиза

## Границы v1.0

Локальная программа с двумя вкладками: нарезка по движению и необязательный
апскейл Real-ESRGAN. Файл/папка, пресеты, настройки, отмена, журнал, предпросмотр,
безопасное сохранение, быстрый/точный экспорт. По уточнению пользователя для
первого GitHub-релиза обязательны установщики Windows (.exe, Inno Setup),
macOS (.pkg) и Linux Debian/Ubuntu (.deb), с включёнными FFmpeg/FFprobe.
Модели улучшения скачиваются отдельно из официального репозитория.
[Требования к установщикам](INSTALLERS.md).

Базовая ОС проверки — macOS arm64 по доступной машине; решение предварительное.
Windows/Linux считаются неподтверждёнными до фактической проверки. Поддержку
GPU-апскейла подтверждаем отдельно от запуска интерфейса.

Не входят: распознавание объектов, редактор таймлайна, полноценный видеоплеер,
возобновление после перезапуска, фоновая автозагрузка моделей,
поддержка всех архитектур и всех дистрибутивов Linux.

## Последовательность

Каждый пункт — отдельная сессия, ориентир 1–4 часа и резерв до 5 часов.
Длительность не гарантирована; крупные дополнительные дефекты выделяются отдельно.

1. **Выполнен.** Исходная точка, Git, зависимости, инструкция, тестовые материалы.
2. **Выполнен.** Защита исходников и результатов, уникальные временные папки.
3. **Выполнен.** Общий запуск внешних программ и понятная диагностика.
4. **Выполнен.** Потокобезопасный GUI, состояния и ограничение очереди.
5. **Выполнен.** Полноценная отмена и закрытие приложения.
6. **Выполнен.** Валидация, сохранение и миграция настроек/пресетов.
7. **Выполнен.** Разделение обработки и интерфейса на модули.
8. **Выполнен.** Временные границы и логика сегментов.
9. **Выполнен.** Предсказуемый детектор, пропорции, запас до/после движения.
10. **Выполнен.** Репрезентативная автонастройка чувствительности.
11. **Выполнен.** Быстрый/точный экспорт и проверка результатов.
12. **Реализован; аппаратная проверка не выполнена.** Совместимость моделей и интеграция Real-ESRGAN.
13. **Выполнен.** Ограничение расхода диска и сохранение тайминга апскейла (FFmpeg проверен, нейросеть имитировалась).
14. **Выполнен.** Пакетная обработка и отчёт о запуске.
15. **Выполнен; проверка по скриншотам не подтверждена.** Темы, компоновка и понятность интерфейса.
16. **Реализован; запуск Actions ожидает подключения репозитория.** Автоматические проверки и GitHub Actions.
17. **Обязательная упаковка и установка в чистой среде** — отдельные сессии,
    каждая ориентировочно до 5 часов:
    - 17.1 Самодостаточная сборка, комплектные FFmpeg/FFprobe, фиксированные версии и лицензии.
    - 17.2 Windows x64: .exe через Inno Setup, установка/обновление/удаление.
    - 17.3 macOS arm64: .app внутри .pkg, проверка путей и установки.
    - 17.4 Linux amd64 Debian/Ubuntu: .deb, зависимости и desktop entry.
    - 17.5 Отдельные модели: ссылка на репозиторий, пользовательская папка и выбор моделей/движка.
    - 17.6 Проверка Windows в чистой среде без Python и системного FFmpeg.
    - 17.7 Аналогичная проверка macOS, решение по подписи/нотаризации.
    - 17.8 Аналогичная проверка Linux, перечень реально поддержанных версий ОС.
18. Документация GitHub, скриншоты, лицензия, шаблоны Issues.
19. Проверка кандидата в релиз.
20. Публикация репозитория, тега и GitHub Release v1.0.0.

После каждого пункта: отдельный коммит, запись проверок и ограничений.
Известные дефекты старой версии устраняются в соответствующем пункте;
первый этап сохраняет её поведение.
