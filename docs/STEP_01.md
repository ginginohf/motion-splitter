Команды повторения после установки зависимостей:

```sh
python tools/generate_fixtures.py  # один раз: существующие видео не перезаписывает
python tools/check_baseline.py
python -m pip check
```

`check_baseline.py` перезаписывает только свои тестовые копии и результаты
в `tests/output/`. Не передавайте ему личные материалы. Результат измерений
сохраняется в `tests/output/baseline.json`.
