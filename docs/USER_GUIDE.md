# Руководство пользователя

[Главная](../README.md) · [Решение проблем](TROUBLESHOOTING.md)

## Нарезать видео

1. Откройте вкладку «Нарезка по движению».
2. Нажмите «Выбрать видео» для одного файла или «Папка» для всех подходящих
   видео непосредственно в каталоге. Поддерживаемые расширения: MP4, MOV,
   AVI, MKV, M4V, WebM; доступность кодеков зависит от внешних инструментов.
3. Выберите режим сохранения и способ поиска движения.
4. Нажмите «Нарезать видео» внизу окна.

Для первого опыта подойдёт короткое видео и автоматическая настройка.
Настройки восстанавливаются с прошлого запуска: проверьте, что выбран нужный режим.

| Режим сохранения | Когда выбирать | Особенности |
|---|---|---|
| Быстро · без перекодирования | Нужно сохранить потоки без повторного сжатия | Границы зависят от ключевых кадров; возможны лишние кадры |
| Точно · MP4, до кадра | Важны границы фрагмента | Перекодирование занимает больше времени; H.264/AAC, исходное разрешение с дополнением нечётных размеров |

Берутся первый обычный видеопоток и первая аудиодорожка, если она есть.
Другие дорожки, главы и субтитры не переносятся. Детектор анализирует изменение
яркости, поэтому движение камеры и смена света тоже могут считаться движением.

## Настроить поиск движения

Список «Поиск движения» переключает автоматическую настройку и ручной порог.
При автонастройке программа оценивает несколько участков ролика; коэффициент
масштабирует полученный порог. **Меньше число — выше чувствительность** в обоих
режимах. Автонастройка — отправная точка, а не гарантия обнаружения каждого события.

Нажмите «Точная настройка движения», чтобы раскрыть дополнительные поля:

| Настройка | Влияние |
|---|---|
| Минимальное движение | Отбрасывает слишком короткие события |
| Пауза между событиями | Сколько неподвижности нужно для завершения события |
| Объединять через паузу | Соединяет близкие фрагменты, включая промежуток между ними |
| Добавить до/после движения | Сохраняет контекст вокруг найденного события |
| Сглаживание | Подавляет короткие изменения, но может скрыть короткое движение |
| Размер анализа | Уменьшает изображение только для поиска движения, сохраняя пропорции |
| Пропуск кадров | 0 — все кадры; 1 — каждый второй; 2 — каждый третий. Большие значения могут пропустить события |
| Если движения нет | Включите, чтобы сохранять видео целиком при отсутствии подходящих событий |

Числа меняются стрелками, с клавиатуры или колёсиком, когда поле выбрано.
Десятичный разделитель — точка. Без фокуса на числовом поле колесо прокручивает
форму. Tab перемещает фокус и прокручивает форму к выбранному полю.
[Точные правила и ограничения алгоритма](REFERENCE.md).

## Наборы настроек

Раскройте «Мои наборы настроек», нажмите «Сохранить набор» и введите имя.
Список позволяет применить сохранённый набор; «Удалить» удаляет его после подтверждения.

«Сохранить настройки» внизу окна запоминает текущие значения, не переписывая
сам набор. При следующем запуске восстанавливаются последние сохранённые
значения, даже если они отличаются от выбранного набора. Параметры также
сохраняются перед началом обработки.

Настройки находятся в `~/.motion_splitter_settings.json` (домашняя папка пользователя).
Текущая схема — 6. Старые значения мигрируют; при повреждении создаётся резервная
копия `.recovery-<id>.bak`. Файл более новой схемы старая программа не перезаписывает.
Проверяются все параметры, в том числе временно скрытые разделы.

## Улучшить качество

1. [Скачайте движок и модели](MODELS.md) из официального источника.
2. Во вкладке «Улучшение качества» раскройте «Подключить движок и модели».
   Укажите исполняемый файл Real-ESRGAN и папку с парами `.param`/`.bin`.
3. Нажмите «Проверить файлы». Это проверка файлов; реальная проверка GPU
   выполняется автоматически перед обработкой.
4. Выберите видео, тип модели и доступный масштаб, нажмите «Улучшить видео».

Для улучшения сегментов сразу после нарезки включите «Улучшить качество после
нарезки». Ссылка «Настроить улучшение →» ведёт к общим параметрам второй вкладки.

| Подпись в интерфейсе | Модель | Масштаб |
|---|---|---|
| Обычное видео · x4plus | realesrgan-x4plus | ×4 |
| Анимация · x4plus-anime | realesrgan-x4plus-anime | ×4 |
| Аниме · animevideov3 | realesr-animevideov3 | ×2, ×3, ×4 |
| Восстановление · realesrnet | realesrnet-x4plus | ×4; файлов нет в проверенном архиве, нужны совместимые веса отдельно |

В «Производительность и место на диске» доступны размер блока (0 — автоматически;
вручную 32–8192), номер видеокарты, лимит временных файлов и резерв свободного места.
По умолчанию лимит — 32 ГиБ, резерв — 2 ГиБ. Большой ролик лучше сначала нарезать.
Список допустимых масштабов зависит от модели. При выборе набора с несовместимыми
параметрами запуск выдаст ошибку, а не подменит модель.

Масштаб ×4 увеличивает ширину и высоту в четыре раза: число пикселей растёт в 16 раз.
Улучшение не восстанавливает гарантированно настоящие детали и может создавать
артефакты. Проверяйте результат на коротком фрагменте.

## Найти результат и остановить работу

Пример структуры (имена условные):

```text
motion_splitter_run_<дата>_<id>/
    report.json
    logs/
    demo.mov/
        demo_segment_01.mp4
        demo_segment_02.mp4
```

Расширение зависит от режима; при улучшении результат получает `_upscaled.mp4`.
Повторный запуск создаёт отдельную папку. Журнал показывает путь результатов
и отчёта `report.json`, в котором перечислены исходники, результаты и ошибки.
Ошибка отдельного видео обычно не мешает обработке следующих файлов.

«Прервать» или Escape запрашивает отмену. Уже готовые файлы остаются;
незавершённый файл не публикуется. Закрытие окна во время работы сначала
останавливает задачу. Зависший вызов декодера может задержать отмену.
Одновременно выполняется только одна задача. Изменённые во время работы
параметры относятся к следующему запуску.

Приложение не отправляет видео и журналы автоматически. Кнопка скачивания моделей
открывает внешний сайт в браузере. Перед размещением отчётов в публичном Issue
уберите личные пути, имена и другую приватную информацию.
