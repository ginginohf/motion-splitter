# Этап 12 — совместимость и интеграция Real-ESRGAN

Реализован программный контракт стандартного ncnn-vulkan; реальная модель/GPU
на этой машине не проверена: исполняемый файл отсутствует. До первого релиза
нужно выполнить аппаратный smoke test и обработку контрольного видео.

## Изменения

- Единый каталог моделей в realesrgan_config.py; x4plus/x4plus-anime/net — ×4,
  animevideov3 — ×2/×3/×4. Новое значение по умолчанию: realesrgan-x4plus.
- Старый general-x4v3 сохранён в настройках без незаметной замены, но недоступен
  в списке новых вариантов и отклоняется при запуске улучшения с объяснением.
  Схема 4; старые настройки и пресеты остаются читаемыми.
- Проверяются масштаб, Tile (0 либо 32–8192), GPU ID, непустые читаемые .param/.bin,
  имена animevideov3-xN. Передаётся абсолютный каталог models рядом с бинарником.
  Ограничена длина пути модели из-за буфера upstream в 256 байт.
- До анализа/извлечения кадров обе задачи запускают маленький PNG через ту же
  конфигурацию, с отменой и тайм-аутом 120 секунд. Проверяется реальный выходной
  PNG и размер. Пробный запуск один на задачу; журнал остаётся, PNG удаляются.
- После обработки проверяется полная последовательность кадров, формат,
  читаемость и ожидаемый размер. Нулевого кода выхода теперь недостаточно.
- Устаревшая функция прямого видео-апскейла явно отклоняет вызов; стандартный
  бинарник принимает изображения. Старые имена импортов сохранены.
- tools/check_realesrgan.py позволяет выполнить отдельную аппаратную проверку.

## Проверки

114 unittest пройдены на macOS arm64. Новые проверки покрывают отсутствующие и
пустые файлы моделей, недопустимые параметры, абсолютный путь, масштабы anime,
отмену, ошибку GPU с сохранением лога, нулевой exit без PNG, отсутствие/порчу/
неверный размер кадра, старые настройки, остановку обеих задач до анализа.
Полный цикл извлечение → отдельный процесс-имитатор → сборка проверен настоящим
FFmpeg: два кадра 32×32 преобразованы в два кадра 128×128. Имитатор делает resize,
не нейросетевой апскейл. Исходные проверки защиты файлов и отмены сохранены.

Настоящий Tkinter: нарезка + имитация улучшения, настройки/пресеты — пройдены.
Тестовые подмены предварительной проверки указаны явно; они не подтверждают GPU.

## Ограничения и следующие проверки

Поддерживаются только перечисленные модели стандартного комплекта и один GPU.
Проба 32×32 проверяет запуск, но не качество/память на большом видео. Содержание
моделей не проверяется криптографически. Чёрные кадры могут пройти валидацию.
Windows/Linux и реальные GPU остаются неподтверждёнными. Расход диска, VFR,
кодеки и контейнер покадровой сборки — этап 13; публикация релиза пока не готова.

Основания: [официальный CLI](https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan#computer-usages),
[выбор файлов и обработка ошибок в исходном коде](https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan/blob/master/src/main.cpp).
